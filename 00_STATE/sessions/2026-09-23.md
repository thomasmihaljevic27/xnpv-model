# Session 2026-09-23 — why the goalie participation model was too sure

The goalie control-year evaluation repairs closed (`ea720e6`, merged). One wording correction came
with it: the pooled season diagnostics "did not detect miscalibration in the statistics tested",
which is weaker than "calibrated", because pooled checks can pass while a subgroup fails. The report
was rewritten, and the 22i state entries were marked [CORRECTED 2026-09-23].

## The investigation

`run_goalie_participation_top.py` v1.0.

**Where the miss sits.** The confident fifth (predicted 0.95, observed 0.86):
- is calibrated on the 2015-2017 pages and misses on 2018-2020;
- by target season, is worst in 2023 (0.95 against 0.59);
- by horizon, is worst three seasons out (0.95 against 0.62).

105 missed cells over 61 goaltenders; in 81% of them the goaltender never played again. Examples:
Luongo (last season 2018) predicted 0.91 for 2023, Darling 0.94, Condon 0.96. It is not a key
break (1%).

**The mechanism.** The vendor contract export is a snapshot: every contract ends in 2018 or later.
On early pages, "known to the export" and "under a visible contract" therefore mean "went on to sign
into the export's era". Up to 2015, every goaltender under a visible contract played, at horizons 0
and 3. From 2019 nearly all are known, and the known-but-unsigned play about half the time.

The 2020-page fit three seasons out could not support "under contract", so it kept only "unknown",
and "known" gave retired goaltenders 0.92-0.96. This is the same selection as the birthdate finding,
from the same source. I had assumed a long-term-injury story (contracts running through injury)
before looking; the data showed the export's coverage instead.

**The candidate.** `ParticipationModel(contract_state="observable")`, in `participation_model.py`
v1.6. Contract state is stated only for seasons from the export's earliest end year, and the
known-to-export signal is dropped. It is opt-in; the default is unchanged.

Results:
- **Brier** 0.2056 -> 0.1940 (100% of resamples).
- **Season WAR RMSE** 2.073 -> 2.062 (100%).
- **The confident fifth** goes from +0.096 to +0.005.
- **Against no contract data**, it wins 93% (Brier) and 97% (WAR squared error).

**The contract dollars.** Each control-year run refits its lines on its own forecast. A first read
compared the two runs' printed RMSEs and showed the candidate worse. That comparison was against two
different targets, the same error the last review caught, so both runs' drawn paths were repriced on
one fixed line, with the realised target asserted identical. On that line:
- **Production:** squared dollar error ties (51%, 58%), and its bias falls +0.566 -> +0.187.
- **Rate:** squared error is slightly worse (24%, 30%), and its bias goes -0.159 -> -0.475.

Within each run, production's contract PIT mean moves 0.438 -> 0.472 (now inside its interval), and
the floor excess moves +13.9 -> +7.1 (production) and +10.2 -> +4.1 (rate).

## Plumbing and checks

- The control-year runner takes `--participation` and pickles draws for cross-run repricing.
- Goalie outputs are byte-identical at default (rechecked on the final code).
- **Check 41:** contract state is read only where the export can see it. A mutant that ignores the
  option fails.

Suite **41 passed, 0 skipped, 0 failed**.

## Left open

- **DECISION (Thomas):** adopt the observable definition for goalie participation. It clearly wins on
  participation; in dollars it removes most of production's bias without lowering squared error.
  Adopting it means rerunning the goalie chain.
- **Skaters:** their contract features read the same export. The skater contract ablation and the
  open contract-data decision were measured with contract state as known, so the matched test should
  use the observable definition.

# Session 2026-09-23b — the period indicator separated from contract status

The review of `c4ddcf0` (`9cddb43`, merged) found that the "observable" definition carries two new
inputs, not one. The "unknown" column became a before/after-2018 period indicator, the same for
every goaltender targeting a season. The gain I credited to contract information had not been
separated from it. The review was right, and this is the second time the same correction has come
back (the goalie price slope, 2026-09-22), so it is now a rule in CLAUDE.md.

## Done

**Five named specifications.** `run_goalie_participation.PART_VARIANTS` (`part_settings`) names
them, and the scored arms and the price runner read the same table: as_known, none, observable,
period_only, contract_only. The default is unchanged. `run_goalie_control_years.py` v1.3 takes
`--participation <variant>`; the period-only specification was carried through it.

**Participation and season** (`run_goalie_participation_top.py` v1.1), reproducing the review:
- period only 0.1927 / 2.062;
- observable 0.1940 / 2.062;
- contract only 0.1956 / 2.065;
- none 0.1958 / 2.065;
- current 0.2056 / 2.073.

In paired resamples:
- period only beats none in 100% / 99%;
- contract only beats none in 67% / 51%;
- period only beats observable in 91% on Brier (tied on WAR).

Every replacement removes the confident-fifth over-prediction.

**A new diagnostic.** For the model with no contract inputs, observed minus predicted participation
by target season shows no step at 2018: within ±0.06 every year, with every interval including zero.
So the period indicator's gain is not a league-wide change in the playing rate. It sits at three to
five seasons out on the later pages, at a boundary set by the vendor's coverage year.

**Contract dollars, one fixed line** (squared error; beats current):
- production: observable 51%, period only 33%;
- rate: 24% and 10%.

Production's bias: +0.566 (current), +0.187 (observable), −0.064 (period only). No replacement
improves the primary dollar score.

**Withdrawn:**
- the attribution of the gain to contract information;
- "noise dominates the dollar error" (the experiment shows this change doesn't lower it, not why);
- the recommendation to adopt the observable definition.

**Also:** check 41 reworded (contract state is the export's, true only under the completeness
assumption). CLAUDE.md gains two rules: don't credit a multi-part change to one part, and don't
compare scores whose targets differ.

Suite **41 passed, 0 skipped, 0 failed**.

## Open

**DECISION (Thomas): which replacement for goalie participation, if any.**
- **none:** simplest; removes the over-prediction.
- **period only:** best on participation, tied to the coverage year, worst in dollars.
- **observable:** in between.

The untested alternative to a 2018 step is recency weighting of the training rows. Skaters: the
matched contract-data test should separate the period indicator from contract status in the same way.
